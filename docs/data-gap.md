# Data Gap

Berkas ini mencatat kebutuhan data atau informasi yang belum tersedia di `docs/fakta-resmi.md` saat sebuah komponen atau halaman situs memerlukannya. Sesuai aturan proyek andikadev.com, dilarang keras mengarang atau mengasumsikan fakta, klien, testimoni, angka statistik, tahun pengalaman, sertifikasi, penghargaan, harga, maupun studi kasus. Jika ada bagian situs yang membutuhkan data yang belum tercantum, bagian tersebut harus dihapus dari halaman dan kebutuhannya didokumentasikan di sini agar dapat dilengkapi atau diverifikasi oleh pemilik.

## Catatan Kebutuhan Data Saat Ini

- Verifikasi URL profil media sosial: URL profil sosial selain yang tertulis penuh dibentuk dari handle (misalnya https://www.instagram.com/andikaputradev). Pemilik perlu memverifikasi tiap URL sebelum dimasukkan ke dalam JSON-LD sameAs atau tautan eksternal situs.
- Konfirmasi nama merek: Nama merek "AndikaDev" saat ini berstatus asumsi dan memerlukan konfirmasi resmi dari pemilik.
